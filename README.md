### Actions during runtime

* L - removing character from scene
* R - resets scene 
* A and D - directional movement
* Space - jump
* I - toggle through different characters/items in the project
* T and Y - toggle through blocks

### Known bugs

* Sometimes directional input doesn't sync with what the sprite should be
